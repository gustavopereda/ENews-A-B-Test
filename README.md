# E-News Express A/B Testing 

## Overview
Conducted an A/B test to compare two landing page designs for an online newsletter. Evaluated which version yielded higher engagement and conversions.

## Key Results
- Statistically significant increase in time spent on the new page
- No significant difference in conversion by language preference

## Tools Used
- Python (SciPy, Pandas, Seaborn)
- Z-Test, Hypothesis Testing
- Jupyter Notebook

## Deliverables
- A/B test design and implementation
- Statistical validation and visualizations
- Recommendations for implementation

## Recommendation
Deploy the new landing page as default and continue testing new variations to optimize performance.
